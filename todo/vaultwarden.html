Set up Vaultwarden (passwords) Bitwarden apps and the web vault only work over HTTPS, so Vaultwarden needs the Tailscale or Cloudflare remote option. With Tailscale, run sudo tailscale serve --bg --https=8443 http://localhost:8094 and open the https link it prints. Create your account there (invite yourself first from /admin with the admin password), turn on two-step login, then point the Bitwarden app and browser extension at that address (choose "self-hosted").

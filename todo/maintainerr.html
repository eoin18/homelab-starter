Connect Maintainerr to Jellyfin Open Maintainerr → Settings: choose Jellyfin (http://host.docker.internal:8096, API key from Jellyfin → Dashboard → API keys), then add Radarr (http://host.docker.internal:7878) and Sonarr (:8989) with the API keys from their Settings → General. Then create a rule, e.g. "watched and older than 60 days". Rules only collect media until you set a delete delay, so nothing is removed without warning.
